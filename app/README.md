# 🔥 봉수대 — 누구의 말이 실제 행동으로 이어지는가

D4D × EDTH Korean Defense Tech Hackathon · T2 OSINT (과제 05 Gray-zone Early Warning + 01 Fusion OSINT Copilot)

> 정보부대는 전국의 첩보를 모아, **독립적으로 겹치는 것만 정보로** 판정한다.
> 봉수대는 그 일을 공개정보로 하고, **그 판단이 과거에 맞았는지까지** 숫자로 낸다.

## 실행
```bash
python3 server.py          # http://127.0.0.1:8790
```
- LLM: OpenRouter 경유 Claude (`~/.config/openrouter/key`) · 지도: Leaflet + Esri Dark Gray
- 링크: `/` 말→행동 판정 · `/?c=N` 질의 예시 N번(사전 실행본 재생) · `/#tac` `/#sea` `/#iran` 상세 · `/#trend` `/#tech` `/#how` 부록 · `/web/pitch.html` 발표
- 실시간 스트림: `GET /api/stream?q=질문` (Server-Sent Events: plan → tool → result → check → verify → done → answer)

## 핵심 결과 — 첫 화면

공식 주체의 '앞으로 할 행동' 예고 → 2~7일 안에 실행됐나. **기준선** = 아무 날이나 찍었을 때 2~7일 안에 사건이 있을 확률. 판정 원칙: 95% 구간(Wilson) 하한이 기준선의 1배를 넘으면 **신호**, 걸치면 **미결**.

| 주체 | 예고 → 7일 내 실행 | 기준선 | 배수 | 판정 | 비고 |
|---|---|---|---|---|---|
| 북한 (2024 오물풍선) | 6/9 | 11.1% | **6.0배** | 신호 | 규칙을 이 기간에서 고름(할인) · 살포 9건 중 예고 없는 3건 |
| 중국 해경·정부 (2024 남중국해) | 4/20 | 14.8% | 1.4배 | 미결 | **규칙 고정 후 처음 적용한 진짜 시험** · 충돌 6건 중 사전 경보 3 |
| 이란 ↔ 이스라엘·미국 (2024~2026) | 수집 중 | — | — | 판정 보류 | Google 뉴스 일시 차단(503) 후 6초 간격 재수집 |

**결론**: 북한의 예고는 신호다. 중국 해경·정부의 경고는 기준선과 구별되지 않는다 → 이 주체에는 말이 아닌 다른 계열(AIS 항적·위성)이 필요하다.

## 신뢰도 · 검증
- 출처 계열: 북측 발표 · 군 발표 · 중국 당국 · 필리핀 정부 · 이란 당국 · 이스라엘·미국 정부 · 언론 · 논문 · 특허 · 시장 데이터
- 같은 발표를 받아쓴 기사 N건 = 원천 1개. 발표 계열이 있으면 그걸 받아쓴 언론은 독립 출처로 세지 않음
- 등급: 단일 1 · 교차 2 · 다중 3+ · 집계(봉수대 자체 계산)
- 3중 검증: ① 도구 결과에 없는 숫자 ② 증거에 없는 인물·기관명 ③ 검증자 LLM(다른 맥락 숫자 붙이기) — 심은 오류 2/2 탐지. 요약도 검증 통과 문장으로만 재작성. 검증자 오류 시 '미검증' 표시

## 적대적 검증 이력 (실패 포함)
1. 기사량만 세기 → 남측 단체 살포·정치 공방에도 튐 → 폐기
2. 정규식 규칙 → 끼워 맞추기 → 폐기, LLM 분류기(프롬프트 고정)
3. 기사 날짜 ±1일 누설 → 적중을 '2~7일 뒤'로만
4. 받아쓰기 기사를 여러 출처로 셈 → 원천 묶기
5. 규칙 고정 후 예고 없는 재개 0/2 → 두 번째 계열(풍향·남측 전단 보도) 둘 다 실패
6. 정답지를 위키 → 합참·필리핀 정부 발표 인용 보도로
7. 코파일럿: 내부 집계를 언론으로 셈 → 분리 / 다른 맥락 숫자 → 검증자
8. 기술 봉수 66% → 대조군 비교로 정정(드론 군집만 우위, 극초음속은 대조군보다 못함)
9. 기준선 도입 → 북한 6배 vs 중국 1.4배. 구간이 1배 걸치면 '미결'

## 기존 자산 / 해커톤 신규
- **기존**: NAIS AI 해커톤(2026-09-30~10-01) 에이전트 원칙(도구 결과로만 답, 없는 숫자 문장 버림), 기준일 가림 백테스트 틀
- **신규**: 국방 OSINT 수집기(한·영) · 예고 분류기(한·영·이란 양방향) · 원천 묶기 · 기준선·구간 판정 · 검증자 · 실시간 스트림 · 지도 · 정답지(합참·필리핀 정부·공식 발표 인용) · 화면 전체

## 한계 (발표에서 먼저 말한다)
- Google 뉴스 RSS는 보도량의 표본(요청당 100건 상한, 날짜 ±1일), 대량 요청 시 일시 차단
- 표본이 작다(북한 9묶음, 중국 20묶음) → 구간을 그대로 그린다
- 예고 없는 도발은 말 계열로 못 잡는다 → 주체별 '예고 없이 일어난 사건' 수를 따로 표시
- 지도 위치는 지역 수준 대략 위치
- 레이저·전자전 논문은 OpenAlex 한도로 미수집(특허만)
